# 5 Tecnologias para desarrollo web

## 1.- [JavaScript](https://developer.mozilla.org/es/docs/Web/JavaScript)

Le da vida e interactividad a las paginas web. Con este lenguaje, el navegador puede reaccionar a las acciones del usuario en tiempo real (como enviar un formulario sin recargar, mostrar animaciones o actualizar datos en vivo), haciendo que un sitio plano se convierta en una aplicacion dinamica. Esto sirve bastante cuando eres una empresa de renombre como:
- Meta
- Netflix
- Microsoft
- Uber
- YouTube

## 2.- [HTML](https://developer.mozilla.org/es/docs/Web/HTML)

Sirve como el esqueleto digital de cualquier sitio web. Su funcion es estructurar el contenido de una pagina (parrafos, titulos, listas o imagenes) utilizando etiquetas que le indican al navegador exactamente que funcion cumple cada elemento en la pantalla. Algunas empresas que utilizan este lenguaje son:
- Google
- Amazon
- Mercado Libre

## 3.- [CSS](https://developer.mozilla.org/es/docs/Web/CSS)

Es el encargado del apartado visual. Permite enmascarar la estructura HTML con colores, tipografias y efectos visuales, ademas de organizar el maquetado para que las paginas se adapten de forma fluida a cualquier dispositivo, ya sea una laptop o un celular. Aplicaciones multiplataforma suelen usar a menudo este lengueje como:
- Pinterest
- Apple
- Airbnb

Se encarga de procesar datos, gestionar cuentas de usuario e interactuar con bases de datos, siendo el motor principal detras de plataformas tan populares como:
- Wikipedia

## Base de informacion extra:

### Que es backend? 

Existen dos formas: Frontend y Backend
- Frontend:
Cuando usas una app o pagina web, todo lo que ves, tocas o cliqueas sucede en el navegador 
- Backend es el motor invisible que se encarga de realizar el trabajo pesado, procesar las reglas de negocio y proteger informacion confidencial.

### Que es API?

"Interfaz de Programacion de Aplicaciones" Mensajero entre el usuario y el servidor. Lo usas cuando inicias una sesion ya existente sin empezar desde cero, tambien para el clima y mucho mas.
